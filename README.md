# Research Intelligence Agent

An AI-powered investment research agent focused on
US stocks and technology trends.

## Features

- Investment topic discovery
- Research planning
- Web and news search
- Evidence extraction
- Investment analysis
- Reflection and research evaluation
- Bull / Bear case generation
- Investment research report generation
- Research history and user preferences

## Tech Stack

- Python
- OpenAI API
- Tavily Search
- Finnhub API
